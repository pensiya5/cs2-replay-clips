# CS2 Replay Clips

Консольная утилита для Windows, которая находит смерти по HUD в записи CS2 и нарезает вокруг них MP4-клипы длиной **12–20 секунд**. На вход можно подать, например, шестиминутную запись WebM с CDN Valve. Утилита обрабатывает файл локально.

## Требования

- Windows 10 или 11 x64 с Media Foundation. Утилита использует системные кодировщики H.264 и AAC.
- Rust 1.100 или новее и компоновщик для выбранной цели. Сборка проверена на `x86_64-pc-windows-gnu` (MinGW‑w64).
- NASM в `PATH` для сборки с SIMD. Для сборки без NASM добавьте `--no-default-features`.

Готовый `.exe` запускается без Python, FFmpeg и весов моделей.

## Сборка и запуск

В PowerShell из каталога проекта:

```powershell
cargo build --release --locked
.\target\release\cs2-replay-clips.exe --video ".\replay.webm" --save-dir ".\clips"
```

Выходная папка содержит `episode_001.mp4`, `episode_002.mp4` и `episodes.json` с границами и событиями. При повторном запуске уже занятые имена пропускаются. Если событий в выбранном отрезке нет, манифест содержит пустой массив эпизодов.

### Нарезать только часть записи

```powershell
.\target\release\cs2-replay-clips.exe --video ".\replay.webm" --save-dir ".\clips" --start 60 --end 180
```

### Использовать готовые события

Передайте `--events` с JSON-массивом, где `t` — время смерти в секундах от начала исходного файла. В [примере](examples/events.json) события на 30-й и 34-й секундах образуют окно 20–36 секунд, а событие на 90-й секунде — окно 80–92 секунды.

```powershell
.\target\release\cs2-replay-clips.exe --video ".\replay.webm" --save-dir ".\clips" --events ".\examples\events.json"
```

## Как выбираются границы

1. Детектор читает верхнюю часть кадра с частотой 2 кадра в секунду и ищет исчезновение игроков с командных панелей.
2. Вокруг смерти берётся 10 секунд до неё и 2 после. Соседние смерти с разницей не больше 5 секунд объединяются, пока окно укладывается в 20 секунд.
3. У края записи или выбранного диапазона окно сдвигается внутрь. Если весь диапазон короче 12 секунд, эпизод может быть короче.

## Поддерживаемые файлы

- Вход — WebM с 8-битным видео AV1 4:2:0 и чётными размерами кадра. Звук может отсутствовать. Поддерживаются Vorbis и Opus, моно и стерео, 44,1 или 48 кГц.
- Выход — MP4 с H.264 и AAC, когда во входном файле есть звук. Длина видеодорожки определяется границами окна. AAC может добавить к общей длительности контейнера один короткий блок.
- Автоматический поиск рассчитан на раскладку HUD реплеев Valve. Для записи с другой раскладкой или скрытым HUD используйте `--events`.
